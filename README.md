## 🎯 About This Project

Welcome to the **Pull-N-Merge** practice repository!  

This hands-on project is designed for participants of the *Pull-N-Merge* workshop. Here you will practice real-world open-source contribution workflows:

- Creating and managing repositories  
- Making meaningful commits  
- Working with branches  
- Opening high-quality Pull Requests  
- Collaborating using GitHub best practices  

By the end of this workshop, you will have made your first (or many) open-source contributions and built confidence to contribute to real projects.

---

## 🛠️ Project Overview

**Pull-N-Merge Toolkit** is a simple, beginner-friendly web application that helps learners:

1. Understand Git & GitHub concepts interactively  
2. Practice contribution workflows  
3. Track their learning progress  
4. Explore open-source contribution tips  

The codebase intentionally contains **issues of varying difficulty levels** so that everyone — from complete beginners to intermediate developers — can contribute meaningfully.

## 🚀 Getting Started

### Prerequisites
- A GitHub account  
- Git installed on your machine  
- A modern web browser  
- (Optional) VS Code or any code editor  

### How to Contribute (Step-by-step)

1. **Fork** this repository  
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/pull-n-merge.git
   cd pull-n-merge
   ```
3. Create a new branch:
   ```bash
   git checkout -b fix/issue-number-short-description
   ```
4. Make your changes  
5. Commit with a clear message:
   ```bash
   git commit -m "fix: resolve issue #12 - add dark mode toggle"
   ```
6. Push to your fork:
   ```bash
   git push origin fix/issue-number-short-description
   ```
7. Open a **Pull Request** against the `main` branch of this repository  
8. Wait for review & merge 🎉

## 📋 Issue Levels

We have prepared issues at three difficulty levels:

| Level | Label | Who should pick this? | Examples |
|-------|-------|-----------------------|----------|
| 🟢 Easy | `good-first-issue` | Absolute beginners | Fix typos, update README, add comments, simple CSS changes |
| 🟡 Medium | `medium` | Participants with some coding experience | Implement small features, fix bugs, improve accessibility |
| 🔴 Hard | `advanced` | Intermediate developers | Add new major features, refactor code, improve architecture |

Browse open issues → pick one that matches your level → comment “I’d like to work on this” → start coding!
