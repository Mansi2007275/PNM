# Contributing to Pull-N-Merge

Thank you for your interest in contributing! 🎉  
This repository exists specifically so that workshop participants can practice the complete open-source contribution workflow in a safe and friendly environment.

## Code of Conduct

Be kind, respectful, and supportive. We are all here to learn.

## How to Contribute

### 1. Find an Issue
- Go to the [Issues](https://github.com/YOUR-ORG/pull-n-merge/issues) tab
- Look for issues labeled:
  - `good-first-issue` → Easy
  - `medium` → Intermediate
  - `advanced` → Challenging
- Comment on the issue:  
  > I’d like to work on this!

### 2. Set Up Locally
```bash
git clone https://github.com/YOUR-USERNAME/pull-n-merge.git
cd pull-n-merge
git checkout -b type/issue-number-short-description
```

Recommended branch naming:
- `fix/12-typo-in-readme`
- `feat/15-add-dark-mode`
- `docs/18-improve-contributing-guide`

### 3. Make Changes
- Keep changes focused on one issue
- Write clear, readable code
- Follow existing code style
- Test your changes in the browser

### 4. Commit Messages
Use conventional commits style:

```
type: short description

Examples:
fix: correct typo in Git cheat sheet
feat: add contribution counter
docs: update setup instructions
style: improve button hover effects
```

### 5. Open a Pull Request
- Push your branch
- Open a PR against `main`
- Fill in the PR template (if available)
- Link the related issue using `Closes #12` or `Fixes #12`

### 6. Review Process
- Maintainers will review your PR
- Address any requested changes
- Once approved, your PR will be merged!

## Development Tips

- Open `src/index.html` directly in your browser to test
- No build step required — pure HTML, CSS & JavaScript
- Prefer vanilla JS (no frameworks) to keep it simple for beginners

## Need Help?

- Ask questions in the issue comments
- Reach out to the workshop organizers
- Refer to the [GitHub Docs](https://docs.github.com/en/get-started)

Happy coding and happy contributing! 🚀
